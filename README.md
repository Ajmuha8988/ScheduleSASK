## 📌 Описание проекта
Проект представляет собой полноценное веб-приложение — панель администратора (диспетчера) для ручного управления, формирования и публикации учебного расписания. Система решает проблему сложного документооборота, заменяя громоздкие таблицы Excel на удобный, строго типизированный цифровой интерфейс.

### Основной функционал:
* **Рабочее место администратора:** Интуитивно понятный интерфейс для ручного распределения и закрепления пар за группами, преподавателями и аудиториями.
* **Управление сущностями:** Полный цикл создания, редактирования и удаления учебных групп, списка преподавателей, дисциплин и доступных кабинетов.
* **Реляционная база данных:** Строгая структура хранения данных, исключающая потерю информации об учебных днях, звонках и семестрах.
* **Интерфейс расписания:** Наглядная сетка занятий с удобной фильтрацией для быстрого поиска нужной информации.
